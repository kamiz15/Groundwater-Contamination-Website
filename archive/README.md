# Archived Non-Runtime Files

Files under `archive/` are retained for reference only. The Flask app, Panel
server, PDF generator, and Docker deployment do not import or serve them.

## Contents

- `reference_artifacts/`: expert-provided standalone scripts, CSV inputs, and
  screenshots that are not used by active routes.
- `generated_artifacts/`: local generated outputs kept temporarily for
  traceability.
- `placeholders/`: empty or one-byte placeholders retained instead of deleted.
- `drafts/`: stale UI and PDF metadata drafts that are not wired into runtime
  behavior.
- `legacy_numerical/`: archived combined numerical dashboards. The active
  numerical experience is the orientation-specific horizontal and vertical
  dashboard set.
