A horizontal-flow model that estimates the steady-state length of a mixing-controlled plume (Lmax) from a source of width Sw. The plume length follows from the inverse error function of the reactant-to-total concentration ratio, matching the horizontal numerical implementation used in CAST.

{% endblock %} {% block about_equation %} Lmax = Sw2 16αTh [ erf−1⁡ ( CA γCD+CA ) ] 2 {% endblock %} {% block about_parameters %}

{% endblock %} {% block about_assumptions %}
  • Steady-state condition in a homogeneous and isotropic aquifer.
  • A single-step bimolecular instantaneous reaction confined to the plume fringe.
  • Mixing occurs only transverse to the horizontal groundwater flow.
