A vertically oriented 2D empirical correlation for the steady-state plume length (Lmax), derived from a sensitivity analysis of biodegradation kinetics, flow velocity, transverse vertical dispersivity, source and aquifer geometry, and reaction stoichiometry.

{% endblock %} {% block about_figure %} {% endblock %} {% block about_equation %} Lmax = 0.5 TA2αTv ( γCr Cc ) 0.3 {% endblock %} {% block about_parameters %}
TA
Aquifer thickness (equal to source thickness) [m]
αTv
Vertical transverse dispersivity [m]
γ
Stoichiometry coefficient [-]
Cr
Partner reactant concentration [mg/L]
Cc
General contaminant concentration [mg/L]
{% endblock %} {% block about_assumptions %}
  • A uniform flow field in an aquifer of constant thickness.
  • A completely contaminated aquifer thickness (landfill or boundary source).
