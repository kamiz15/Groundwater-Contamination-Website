A vertically oriented 2D empirical model that extends the Liedl (2005) expression with a recharge-rate correction, quantifying how vertical recharge shortens the steady-state plume length (Lmax).

{% endblock %} {% block about_figure %} {% endblock %} {% block about_equation %} Lmax = ( 1−0.047TA0.404Rc1.883 ) 4TA2 π2αTv ln⁡ ( 4π γCr+Cc Cc ) {% endblock %} {% block about_parameters %}
TA
Aquifer thickness (equal to source thickness) [m]
αTv
Vertical transverse dispersivity [m]
Rc
Recharge rate [m/yr]
γ
Stoichiometry coefficient [-]
Cr
Partner reactant concentration [mg/L]
Cc
General contaminant concentration [mg/L]
{% endblock %} {% block about_assumptions %}
  • Steady-state condition in a homogeneous and isotropic aquifer.
  • Uniform vertical recharge across the plume.
