A vertically oriented 2D hybrid correlation for the steady-state plume length (Lmax), derived from a sensitivity analysis of biodegradation kinetics, flow velocity, transverse vertical dispersivity, source and aquifer geometry, and reaction stoichiometry using a numerical model.

{% endblock %} {% block about_figure %} {% endblock %} {% block about_equation %} Lmax = 0.5 ST2αTv ( γCD0 CA0 ) 0.3 {% endblock %} {% block about_parameters %}
ST
Source thickness (equal to aquifer thickness) (m)
αTv
Vertical transverse dispersivity (m)
γ
Stoichiometry coefficient (-)
CA0
Acceptor concentration at source (mg/L)
CD0
Donor contaminant concentration at source (mg/L)

  • A completely contaminated aquifer thickness (landfill or boundary source).
