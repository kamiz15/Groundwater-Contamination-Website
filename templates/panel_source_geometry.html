Source Geometry Forward Model

Define a regular contaminant source shape (circle, ellipse, or line), set the number of representative source points, and compute the Liedl (2005) plume length from the effective transverse source width. Groundwater flow is assumed to run in the positive x-direction.

How it works: The geometry is mapped to an effective source width W (diameter for circles, minor axis for ellipses, transverse extent for lines). W feeds the Liedl analytical equation as the source-zone height M. The plot shows the source outline, the fitted source points, and the plume plume extending downstream from each point.
