A 2D reactive-transport model based on the conceptual work of Yadav et al. (2014). It follows the same assumptions as Liedl et al. (2005) — homogeneous, isotropic, steady-state, bi-component instantaneous reaction between the electron donor (CD) and the electron acceptor (CA). The MODFLOW 6 GWF/GWT simulation produces a transformed concentration Cc(x,z) that lets the reactive system be simulated as a conservative one. CAST runs the model in both a horizontal (x, y) and a vertical (x, z) orientation.

{% endblock %} {% block about_figure %} {% endblock %} {% block about_equation %} Lmax = max⁡ { x: Cc⁡(x,z) = Cthres } {% endblock %} {% block about_equation_note %}

There is no closed form. The maximum plume length is read from the simulated transformed-concentration field as the largest distance along the x-axis at which the chosen threshold concentration (e.g. Cc=0) is reached.
