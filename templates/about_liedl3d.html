A 3D extension of the Liedl et al. (2005) model for a fully penetrating source of finite width in a domain that is infinite in length and width. The threshold concentration Cthres lets the plume length (Lmax) be measured to any chosen contour along the x-axis.

{% endblock %} {% block about_figure %} {% endblock %} {% block about_equation %} erf⁡ ( W 4αThLmax ) e −αTvLmax (π2TA) 2 = π4 γCthres+CA0 γCD0+CA0 {% endblock %} {% block about_equation_note %}

This equation is implicit in Lmax; CAST solves it numerically by Newton's method.

{% endblock %} {% block about_assumptions %}
  • Steady-state condition in a homogeneous and isotropic aquifer.
  • A single-step bimolecular instantaneous reaction between reactants taking place only at the fringe.
  • The contaminant source (electron donor) penetrates the entire thickness of the aquifer.
