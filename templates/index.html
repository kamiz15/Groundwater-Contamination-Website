Workflow

Suggested workflow

The toolboxes are designed to be used in sequence, from site data to transport models:

  1. Start with the Database Toolbox
  2. Continue with the Analytical or Empirical model toolbox
  3. Run the Numerical model toolbox
  4. Use the AEM Source Designer model
