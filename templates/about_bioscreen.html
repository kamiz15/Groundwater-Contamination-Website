{% extends "model_about_base.html" %} {% block about_category %}Analytical Model{% endblock %} {% block about_title %}BIOSCREEN-AT{% endblock %} {% block back_href %}{{ url_for('analytical_bp.analytical_landing') }}{% endblock %} {% block back_label %}All analytical models{% endblock %} {% block about_lead %}

An exact analytical (BIOSCREEN-AT) solution for the three-dimensional transient transport of a dissolved contaminant undergoing advection, dispersion, equilibrium sorption and first-order decay. The source is a patch specified-concentration boundary. CAST evaluates the solution with Gauss–Legendre quadrature and reports the maximum plume length (Lmax) as the farthest point on the centre line where the concentration still exceeds the threshold.

{% endblock %} {% block about_figure %} {% endblock %} {% block about_equation %} Lmax = max⁡ { x: Cc⁡(x,0,0,t) ≥ Cthres } {% endblock %} {% block about_equation_note %}

The centre-line concentration Cc⁡(x,0,0,t) has no compact closed form; it is the transient advection–dispersion–decay integral of Newell et al. (1997) / Karanovic et al. (2007), evaluated numerically.

{% endblock %} {% block about_assumptions %}
  • The aquifer is semi-infinite in x, infinite in y, and extends from the water table to a relatively large depth.
  • Groundwater flow is steady and one-dimensional.
  • The solute undergoes equilibrium sorption and first-order transformation reactions.
  • The aquifer is homogeneous and Lmax is always found on the centre line.
